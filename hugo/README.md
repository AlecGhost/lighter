# Lighter Hugo Module

A self-contained Hugo module for rendering syntax-highlighted code blocks generated by [Lighter](https://github.com/AlecGhost/lighter) using Catppuccin Mocha tokens.

## Features

- **Zero configuration / Self-injecting**: Loads required CSS and JS assets on-demand only on pages using the shortcode.
- **AST-level Semantic Highlighting**: Colorizes Arborium / Lighter HTML token tags (`<a-k>`, `<a-f>`, `<a-t>`, etc.).
- **Interactive Code Box**: Responsive container with filename / language headers and one-click clipboard copy.

## Installation

Add the module to your `hugo.toml`:

```toml
[module]
  [[module.imports]]
    path = "github.com/AlecGhost/lighter/hugo"
```

## Usage

Place pre-rendered HTML snippets from Lighter in `data/code/` or `assets/code/`:

```markdown
{{< lighter file="example.html" title="main.rs" lang="Rust" >}}
```
